# Swappi

## Description

Swappi is a web app that lets users seamlessly transfer playlists between Spotify and Apple Music. Users can log in to both services, fetch their playlists, match tracks, and create new playlists on the target platform — all while keeping their data private. Most of the logic runs entirely on the client, ensuring secure and fast operation, while a minimal backend only provides the Apple Music developer token needed for authentication. The app is built with React for a responsive web experience and can later be wrapped into a mobile app.
